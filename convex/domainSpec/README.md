# Domain Spec - Convex Runtime Copy

## Overview

This directory contains **copies** of essential files from `packages/domain-spec/` that are needed by Convex functions at runtime.

**Why copies?** Convex functions cannot import from outside the `convex/` directory due to bundling restrictions. See [Convex documentation on project configuration](https://docs.convex.dev/production/project-configuration).

## Source of Truth

**`packages/domain-spec/`** is the canonical source. All edits should be made there.

## Copied Files

- `data.ts` - Game data (rooms, enemies, missions, tools)
- `schema.ts` - Zod validators and TypeScript types
- `runtime.ts` - Runtime utilities (getMissionById, matchesStep, etc.)
- `generated/` - PDDL artifacts (domains, problems, plans)

## Update Process

When you modify `packages/domain-spec/`, you must copy changes to `convex/domainSpec/`:

```bash
# Manual copy (temporary solution)
cp packages/domain-spec/data.ts convex/domainSpec/
cp packages/domain-spec/schema.ts convex/domainSpec/
cp packages/domain-spec/runtime.ts convex/domainSpec/
cp -r packages/domain-spec/generated convex/domainSpec/

# Or use the planning refresh script (recommended)
pnpm planning:refresh
```

## Future Improvement

Consider adding a build step to `package.json` that automatically syncs these files:

```json
{
  "scripts": {
    "sync:domain": "cp packages/domain-spec/{data,schema,runtime}.ts convex/domainSpec/ && cp -r packages/domain-spec/generated convex/domainSpec/",
    "predev": "pnpm sync:domain && convex dev --until-success && convex dashboard"
  }
}
```

## Architecture

```shell
packages/domain-spec/          # Source of truth
├── data.ts                    # ← Edit here
├── schema.ts                  # ← Edit here
├── runtime.ts                 # ← Edit here
├── planning.ts                # (Not copied - build-time only)
└── generated/                 # ← Generated by scripts
    ├── domains/
    └── problems/

convex/domainSpec/             # Runtime copy for Convex
├── data.ts                    # ← Copied from source
├── schema.ts                  # ← Copied from source
├── runtime.ts                 # ← Copied from source
└── generated/                 # ← Copied from source
    ├── domains/
    └── problems/
```

## Why Not Symlinks?

Convex's bundler follows symlinks but still enforces the "no imports from outside convex/" rule, so symlinks don't solve the problem.

## Why Not npm Package?

Publishing `domain-spec` as an npm package would work but adds unnecessary complexity for a monorepo POV project.
