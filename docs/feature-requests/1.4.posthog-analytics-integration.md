# Story: Replace Cache Hit Counter with PostHog Analytics (POV - Optional)

## 📋 Story Overview

**Status**: 📋 Backlog (blocked by Story 1.3)
**Priority**: P4 - Optional (POV stage)
**Effort**: Small (2-3 hours)
**Type**: Analytics Integration (POV Stage)

> **POV SCOPE**: This is optional for POV. Only implement if you need analytics insights. Can be deferred to post-POV phase.

### Problem Statement

Current cache hit counter implementation:

- Stores `hitCount` in `commandOutputCache` table
- Adds database write operation on every cache hit
- Costs ~$2-4/month at 1M cache hits
- Adds 10-20ms latency per cache hit
- Limited analytics capabilities (just a counter)
- **Already removed from atomic cache hit path** (Story 1.1)

### Why PostHog is Better

**Performance**:

- Zero database writes for analytics
- No latency impact on critical path
- Async/batched event delivery
- Free tier: 1M events/month

**Separation of Concerns**:

- Analytics failures don't affect game functionality
- Fire-and-forget event tracking
- Maintains transaction atomicity

**Richer Analytics**:

- User funnels: Cache hit rate by player cohort
- Time-series analysis: Cache effectiveness over time
- Correlation analysis: Cache hits vs. player progression
- Custom dashboards: Real-time cache performance metrics
- Session replay: Actual player behavior
- A/B testing capabilities

## 💡 Proposed Solution

### Implementation Approach

**1. Add PostHog Action** (`convex/analytics.ts`):

```typescript
export const trackCacheHit = internalAction({
  args: {
    playerId: v.string(),
    command: v.string(),
    target: v.string(),
    cacheId: v.id("commandOutputCache"),
    timestamp: v.number(),
  },
  handler: async (ctx, args) => {
    await fetch('https://app.posthog.com/capture/', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        api_key: process.env.POSTHOG_API_KEY,
        event: 'cache_hit',
        properties: {
          player_id: args.playerId,
          command: args.command,
          target: args.target,
          cache_id: args.cacheId,
        },
      }),
    });
  },
});
```

**2. Update Cache Hit Path** (`convex/gameActions.ts:107-172`):

```typescript
if (cached) {
  // ... existing atomic operations ...

  // 🔥 Fire analytics event AFTER transaction completes
  await ctx.scheduler.runAfter(0, internal.analytics.trackCacheHit, {
    playerId: identity.subject,
    command: commandType,
    target: normalizedTarget,
    cacheId: cached._id,
    timestamp: Date.now(),
  });

  return { outputId };
}
```

**3. Remove Old Implementation**:

- Remove `hitCount` field from schema
- Remove `incrementCacheHit` mutation
- Remove `getCacheStats` action (or rewrite to query PostHog)
